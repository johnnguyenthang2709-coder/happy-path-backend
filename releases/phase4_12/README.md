# Phase 4.12 integrated research release

Start with [installation, inputs, queries and limitations](../../docs/phase412_integrated_release.md).

This directory contains author-generated aggregate release metadata, input hashes and actual validation outcomes. It intentionally contains no provider geometries, individual provider metrics, source quotations, private posts, credentials or acquisition databases. The full integrated research dataset and portable exports are generated locally under `exports/route_intelligence/phase4_12_integrated/` and are ignored by Git.

The private handoff is an authorized-transfer input bundle, not a public GitHub artifact. The original source and nationwide raster releases stay untouched. Full historical-snapshot reproduction requires those inputs; the public checkout alone is not a full offline data release.
